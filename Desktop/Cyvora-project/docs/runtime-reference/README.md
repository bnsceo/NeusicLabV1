# Runtime reference bundle

This folder imports the useful reference material from `files6_extracted`.

Use these files as implementation guidance for Cyvora's worker/runtime layer,
budget routing, schema validation, and delivery planning. They are reference
artifacts, not the live execution engine.

Recommended follow-up uses:

- map `schema.py` concepts into Cyvora's worker validation layer
- adapt `BUDGET_AND_ROUTING.md` into harness cost-ceiling logic
- use `MASTER_PLAN.md` and `PHASE_0_QUICKSTART.md` as onboarding/roadmap docs
- translate `cli.py`, `hermes.py`, and `crews.py` into Cyvora task orchestration patterns
